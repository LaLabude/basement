# Basement

Boom-bap tone tool (VST3).

Controls: Drive, Low, Punch, Grit, Needle, City, Mix, Output + Mode switch (Sample / Drums).

- City: New York (Premier) <-> Detroit (Dilla) <-> Los Angeles (Madlib)
- Needle: crackle that is triggered by transients, so the dust plays with the groove
- The top end (above ~3 kHz) is never saturated or crushed, so samples keep their air
